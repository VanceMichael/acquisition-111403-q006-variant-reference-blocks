# 来源资料约定

群体测序资料接收器。现有功能读取单个已整理变异对象；完整交付提供VCF文本分片及独立参考序列标识。只做资料接入。

## 交互与身份

GET /variant 返回已整理对象。GET /shards 列出reference、intervals和文件URL。GET /vcf/:id返回VCF 4.3子集文本；##INFO/##FORMAT中Number=A/R/G分别按替代等位、全部等位和基因型基数解释，GT中的数字索引当前行REF/ALT，.是缺失。<NON_REF>配合END为闭区间参考块，不表示某个实际替代等位。分片边界允许重叠；reference不同不能归并。

## 外部变化

正常资料在 `fixtures/source.mjs`。同一来源可能处于这些外部阶段：reference-change、conflicting-block。集成测试通过来源实例的`setPhase`切换外部状态，这不是线上业务接口。阶段内同一URL的响应可以改变，其余URL保留正常资料；来源的请求轨迹在实例的`requests`中可查，控制方法不对网络开放。未知地址返回404，非法请求返回非成功状态。

## 已有收件边界

当前`src/reader.mjs`只收取/variant提供的已整理资料。归档按资料标识和内容摘要区分版本，原文按响应字节摘要独立存储，打开归档时逐份校验。来源文件、接收记录和对外查询不共享内存对象。未声明的协议能力不作推断；格式子集以本页和实际来源为准。
